# treena

treena is a full coding environment built for mobile. write, run, and ship software entirely from your phone — no laptop required.

this repo contains the static landing page for treena.

## structure

```
index.html   single-file landing page (no dependencies)
```

## running locally

any static file server works:

```bash
npx serve .
# or
python3 -m http.server 3000
```

then open `http://localhost:3000`.
